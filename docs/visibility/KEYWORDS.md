# Local search terms per brand (K1, 2026-10-09)

What people type to find each brand's food near each kitchen, FR and EN. Use them in Google posts, page titles
(`SEO_TITLES.md`), menu item names, review replies and, later, Google Ads. **No search volumes yet:** this session has no
access to Google Ads Keyword Planner; check each term there once the owner connects the Ads account, and drop the ones
with no searches.

## How to build the terms (all brands)

- **Dish + place:** `<dish> <area>` and `<dish> près de moi` / `<dish> near me`, for example `shawarma NDG`,
  `poulet frit Saint-Léonard`, `crêpe near me`.
- **Dish + delivery or pickup:** `livraison <dish> Montréal`, `<dish> à emporter`, `<dish> delivery Montreal`,
  `<dish> pickup`.
- **Late evening:** `<dish> ouvert tard`, `late night <dish>`: **only after the owner approves the hours**, and never
  "24/7".
- **Areas near each kitchen** (delivery radius; only use the ones the kitchen really delivers to):
  - NDG kitchen (6280 Somerled): NDG, Notre-Dame-de-Grâce, Côte-des-Neiges, Hampstead, Côte-Saint-Luc, Montréal-Ouest,
    Westmount.
  - Saint-Léonard kitchen (Jean-Talon E): Saint-Léonard, Anjou, Montréal-Nord, Saint-Michel, Rosemont, Mercier.
- **Never:** competitors' names (Chalet Bar-B-Q, Orange Julep, Mythos, Pizza Pita...) as keywords, in ads or in posts.
- **Negative keywords for Ads (all brands):** recette / recipe, emploi / job / hiring, gratuit / free, calories,
  franchise, menu prix PDF, and the other brands' own names (so two of our brands never bid against each other).
