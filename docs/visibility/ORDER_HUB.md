# Order hub page per brand (H1, 2026-10-09)

Copy for each brand's one ordering page (the "link tree" the owner asked for): the ON2GO brand page or the brand site's
store page, whichever the owner picks (`PLAN.md` Phase 0). **Button order is fixed:** pickup at the counter price first
(no app commission), then the delivery apps that really carry the brand, then Too Good To Go. Only stores that are
live today get a button; "off" stores and stores whose address is in question (`PLAN.md` §7, items 2 and 5) wait.
**Po Poulet NDG on DoorDash (store 27982486) never gets a button.** No hours on the page until they are approved;
never "24/7".
