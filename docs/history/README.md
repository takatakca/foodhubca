# History

These documents are kept for provenance only. They describe earlier release candidates of the
"TAKATAK Accounting Control Tower" (RC2–RC4, Phase 25) whose architecture used UrbanPiper as the
control layer. That architecture is **no longer used**: TAKATAK Food Hub integrates with every
platform directly (see [../LOCKED_DECISIONS.md](../LOCKED_DECISIONS.md)). Nothing in this folder
is a current instruction.

- `RC9_BASELINE.md`, `RC9-BASELINE.md` — the two import manifests of the RC9 source (ZIP hash and transport-archive hash).
- `RC4_AUDIT_REPORT.md`, `RC3_FIXES_APPLIED.md`, `RC2_REVERIFICATION_REPORT.md` — earlier audits.
- `PHASE25_LIVE_CONNECTOR_LAYER.md`, `OPERATIONAL_PLAN.md`, `API_ONBOARDING_CHECKLIST.md` — Phase 25 plans.
- `CODEX_OPERATIONAL_BUILD_PROMPT.md` — the original build brief.
