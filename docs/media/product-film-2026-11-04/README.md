# Food Hub product film — actual local delivery

Four 30-second silent H.264/30fps edits, French and English, landscape and square. The manifest lists final files, posters and captions. These are actual rendered assets, not a storyboard or a claim of Runway generation.

The timeline is: restaurant food photograph (0–4s), real Food Hub new-order/kitchen flow (4–12s), real order status filters (12–18s), real tablet-wall layout controls (18–26s), restaurant photo and Food Hub / TAKATAK closing card (26–30s). Both interface and editorial text match the selected language. Menu dish names remain the synthetic menu's actual data.

Source footage comes from a local production build of Food Hub, driven by the PR140 recorder (source head 8af116a21a186abc390aeee7bce1d86cab31b086) with system-browser support, English-cookie support and scoped automation selectors added outside the app. Fictional customer/order records and localhost service stand-ins were used. Relay windows are neutral local placeholders. No native delivery-platform session or real merchant connection was filmed. This does not establish that 54 authenticated sessions or any production provider connection is running.

Currency text is blurred during capture, following the existing no-prices film brief. Real UI values and API responses were not replaced. Original unredacted fictional-data takes remain outside this final package for internal review. Final posters use the steady frame at 8 s, after the app's entry animation.

Restaurant photos are existing on2goca/public/photos/FYJ5QXV8R7VT2-1200.webp (pizza) and 597X8A3860936-1200.webp (pita). ON2GO's README identifies the photo library as the restaurants' Clover-menu images. Per-file photographer/licence records are not present; this package does not independently certify rights. The image originals were not modified. The rendered film displays/crops them with gentle motion.

Typography and cards follow the current blue/navy brand; no retired gold logo or recreated logo is used. The film has no audio, music, generated voice, paid-provider generation or unproven financial claim. Canva, Runway, ElevenLabs and a personal PC/browser were not accessed. No public upload, social post or deployment is included.

Reproduction: the portable renderer and input contract are at `scripts/media/` in this repository. PR140's original 47-filename inventory is included as `prior-pr140-expected-filenames.csv`. Those historical PC clips are absent here; these four new edits use freshly captured local footage.

Verification results are in verification.json. File properties and captions are checked programmatically; posters and representative footage frames are visually reviewed. Currency OCR sampling is an additional check, not exhaustive frame-by-frame proof. Source and rendering tests do not certify live integration or deployment.
